Pearson vs OOD 일반화. speed@¼·linear는 세 스케일 모두 CI가 0 제외 (linear p≤.018, speed p≤.003). 비대칭(asym) end-to-end는 16k서 유의성 상실(CI[−0.90,+0.34]).
선택성 대조: 실제 타깃 mean R_linear +0.167 vs 셔플 타깃 −0.001 → 추정기는 추출을 재지 용량을 재지 않음.

왜 linear가 뒤집히나: final-pose는 linear-hard(0.06)인데 deep-easy(0.92) = 전형적 shortcut. 반대로 시각 latent은 linear≈0.2인데 deep≈−0.1이라 grounding을 강제하고 돕는다. linear-decodability ⟂ policy-recoverability.

"포화 · 다양성 inert" — 아티팩트로 판명 R3b

개수 sweep은 세팅 결함이었다

ARTIFACT

저-recov 멤버를 1→6개 쌓아도 benefit이 0.035→0.043→0.043→0.047→0.040→0.045로 전부 노이즈(std~0.018) 안. "포화"로 보였지만 —

근본 원인: mix가 멤버 타깃의 concat을 하나의 선형 head가 mean-MSE로 예측 + BC:aux 가중치 1:1 고정 → aux가 backbone에 흘리는 gradient 예산이 멤버 수 K와 무관(각 멤버 1/K). 포화가 loss 정규화로 강제돼 있었음. 다양성 패널도 K=2 고정이라 같은 함정.

정정 실험(countfix) 진행 중: 멤버별 독립 head + loss 합산(각 full weight) + 총-weight 고정 대조(SUM vs MATCHED vs MEAN). SUM이 K에 따라 오르고 SUM>MATCHED면 → "다양한 hard question이 상보적으로 grounding을 더한다"가 증명됨(≠포화). GPU 대기.

개념·측정·서베이 R5 · R6 · R7

R5 · NTP은 형태다

정직

NTP라고 다 저-recov가 아님. LLM NTP는 웹텍스트가 高엔트로피라 low-recov지만, π0.5의 subtask NTP는 장면-결정적 저엔트로피 → 실제로 高-recov(쉬운 태스크). recoverability = 타깃 엔트로피, 형태 무관.

R6 · state-infer가 반례

측정됨

proprio를 마스킹하고 이미지+언어로 pose 추론 = 내가 저-recov로 추정했으나 측정하니 高-recov(+0.72/+0.80). 이미지에서 pose가 읽힘. → 정성적 지도를 측정으로 착각하면 안 됨.

R7 · 필드가 한 축으로

DONE · 정성적

~55개 선행 VLA aux를 recoverability 축에 배치. 필드는 값싼(高-recov) 쪽에 몰려 있다 — MAE/contrastive/VQA·픽셀 next-frame·hindsight-goal 전부 高. 이득은 target 난이도가 아니라 prior 전이·planner 활용에서 옴. retrospective 레인은 거의 비어 있음.

경계 판정: inverse-dynamics는 labeler로선 값쌈(H), o_t만이면 hard(L). latent-action Stage-2가 저-recov 신호. hindsight goal은 궤적 위 = 최대 중복(shortcut).
