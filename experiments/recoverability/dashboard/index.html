Regularizing VLA models by asking hard questions

Method = AHA (Asking Hard-question Auxiliaries). One measurable axis — recoverability — unifies VLA auxiliary objectives and predicts which regularize BC vs. become its shortcut. 이 페이지는 현재 진행상황을 항상 반영하는 라이브 대시보드.

지금 한 줄: 측정 방법론 코어는 탄탄(SOLID, 3스케일+CI), 메커니즘(composition·KI)은 proxy 스케일서 확인, 서베이 완료. 최대 리스크 = 전부 mini-VLA(2.3% 데이터)·offline이라 외적타당성 미검증 → M2(full-VLA closed-loop)가 make-or-break, 코드 ready but GPU 포화로 대기.

Yellow flags (숨기지 않음):
  • 전부 mini-VLA 대리모델 — 외적타당성 미검증. M2가 make-or-break.
  • 데이터 2.3% — 2,000/87,212 에피소드, 16k/~700k transition. + 작은 모델·~500–2,400 스텝 → 절대 일반화 0 근처.
  • offline OOD R² ≠ closed-loop 성공률 — 진짜 지표 미검증.
  • N=12–18, CI 넓음. R4 절반 선점(π0.5). instr-infer는 novelty gap 아님(Hejna 2023).
해소된 것:
  • 통계: 부트스트랩 CI — sign-flip·speed@¼ 3스케일 robust(p≤.003).
  • "스케일서 약해짐": washout 아님 — 점근 측정이 saturate, 동역학은 유지 → "동역학으로 재라" 재강화.
