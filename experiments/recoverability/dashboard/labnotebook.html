측정이 답을 뒤집는다 (sign-flip) R1 · MEASURED

목적

recoverability를 어떤 함수족·어느 시점에 재느냐가 결과를 바꾸는지. 정책이 shortcut을 잡는 방식대로 재야 하는지 검증.

가설 (기대)

문제 (사용자 지적)
저-recov 멤버를 1→6개 쌓았을 때 benefit이 .035→.043→.043→.047→.040→.045로 전부 노이즈(std~.018) 안. "포화"로 보였지만 —
진단 (아티팩트)

mix가 멤버 타깃 concat을 하나의 선형 head가 mean-MSE로 예측 + BC:aux 1:1 고정 → aux가 backbone에 흘리는 gradient 예산이 멤버수 K와 무관(각 1/K). 포화가 loss 정규화로 강제됨. 다양성 패널도 K=2 고정이라 동일.

가설 (정정 실험)
멤버별 독립 head + loss 합산(각 full weight)하면 K배 압력이 실제로 들어감. SUM(K개 다양한 hard)이 총-weight 고정 MATCHED(1개×K)보다 높으면 → 다양한 hard question이 상보적 grounding을 더한다(≠포화). SUM≈MATCHED면 그냥 총 가중치.

개념 부록 §A · 헷갈리는 것들

정책 함수족 (𝒱)

y를 어떤 함수로 예측하느냐. linear probe=고정 DINO 위 Ridge(선형·틀림). 정책 함수족=실제 정책망(학습되는 DINO+transformer)을 end-to-end 학습(맞음). shortcut을 잡는 건 정책이니 정책 함수족으로 재야 함. final-pose: linear .06 / policy .92.

학습 동역학

y를 언제 읽나. asymptotic=수렴 후 최종 loss. dynamics=학습 초반 얼마나 빨리(speed@¼) / 전체 곡선면적(AULC). shortcut=먼저 잡히는 것이라 동역학이 잘 잡음. 스케일 키우면 asymptotic은 saturate, dynamics는 유지.

recoverability vs generalization

다른 것·다른 데이터. recoverability = aux 타깃 y의 예측 난이도(in-dist val). generalization = action의 OOD R². the LAW = 이 둘의 음의 상관.

단일 action이 나쁜 이유

delta action 단일예측은 정적 이미지 하나에서 거의 노이즈(ill-posed) = signal floor. 저-recov지만 학습가능 구조가 없어 grounding 안 됨. → chunk로. cur-action-chunk = BC(자기 자신은 정규화 못 함).

continuous가 VLM을 hurt (deferred)

pretrained VLM은 discrete token NTP로 학습됨 → continuous head가 backbone을 오염(π0.5가 KI하는 이유). VLM-스케일에선 discrete 예측(FAST/VQ/language NTP)이 맞음. RT-1은 LM 아니라 continuous OK. VLA 적용 시 재논의.
